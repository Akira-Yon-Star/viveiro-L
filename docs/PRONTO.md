# Definição de Pronto — Viveiro

> Documento herdado. Última alteração: 2026-09-05.

## Definição geral

Uma história está pronta quando funciona conforme especificado no BACKLOG.md,
atende aos seus critérios de aceitação e é aprovada pelo cliente.

## Critérios de aceitação

Uma história só será considerada pronta quando:

1. O código da funcionalidade estiver implementado.
2. A funcionalidade estiver funcionando corretamente.
3. Os critérios de aceitação definidos no BACKLOG.md forem atendidos.
4. A funcionalidade tiver sido testada pela equipe.
5. Os dados forem armazenados corretamente quando a história exigir persistência.
6. A interface permitir que o usuário execute a ação prevista na história.
7. Não houver erros que impeçam o uso da funcionalidade.
8. A funcionalidade tiver sido apresentada ao cliente.
9. O cliente tiver aprovado a funcionalidade.

## Validação

A equipe deverá verificar cada história individualmente no BACKLOG.md,
comparando os critérios de aceitação com o que foi implementado.

A aprovação do cliente é necessária para que a história seja considerada pronta.
